# Contributing

This repository is intended to be a fast, collaborative hackathon workspace.

## Working agreements

- Keep the problem statement and MVP scope up to date.
- Create small, focused changes.
- Use clear commit messages.
- Do not commit secrets, personal data, generated build artifacts, or large unrelated files.
- Document setup steps and important decisions.
- Raise blockers early.

## Branches and commits

Suggested branch names:

- `feat/short-description`
- `fix/short-description`
- `docs/short-description`

Suggested commit format:

```text
type: short description
```

Examples: `feat: add report submission flow`, `docs: clarify setup steps`.

## Pull requests

Include:
- What changed and why
- How it was tested
- Screenshots or a short demo for UI changes
- Known limitations

Keep reviews constructive and focused on making the project work.
