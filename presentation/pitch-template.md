# Hackathon Pitch Template

Aim for a clear, evidence-led story. Adapt the length to the event's rules.

## 1. The problem

Who has the problem? When does it happen? Why does it matter?

## 2. Evidence

What did you observe, research, or validate? Use one concrete example or metric.

## 3. The solution

What did you build, and how does it improve the current situation?

## 4. Live demo

Show one complete user journey:

1. Start from the user's real problem.
2. Perform the core action.
3. Show the result.
4. Explain what makes the result useful.

Prepare a short recorded backup in case the live demo fails.

## 5. Technical implementation

Explain the architecture, key technologies, and one meaningful technical decision.

## 6. Impact and next steps

What could improve if this were adopted? What remains unbuilt or unvalidated?

## 7. Closing

One sentence that connects the solution back to the problem.

## Demo checklist

- [ ] Demo environment is ready.
- [ ] Test data is available and safe to show.
- [ ] Network/API dependencies have a fallback.
- [ ] The core flow has been rehearsed.
- [ ] The team knows who presents each section.
- [ ] Claims match what the prototype actually does.
